公众号自动排版工具

粘贴 Markdown → 自动排版预览 → 复制到微信公众号编辑器。纯本地运行，不上传文章。

① 粘贴文章 / Markdown

支持标题、列表、引用、加粗、分割线
可用标记：
## 小标题 → 小标题；**加粗** → 加粗；==核心观点== → 酒红色重点；++需要强调的句子++ → 酒红色下划线；{{概念}} → 去掉标记并显示蓝色概念文字（不解释或改写词义）；> 引用 → 引用块。
图片占位可写 [图片：图片内容描述]，点击预览中的搜索按钮可在本页打开 Wikimedia Commons 搜索弹窗，选图后会替换占位符。搜索需要联网；请自行核对来源与授权，显示许可信息不代表已确认可用于公众号。
输入内容后，右侧会自动预览。

② 排版预览

预览区可滚动

文章预览会显示在这里。

搜索可用图片

候选来自 Wikimedia Commons。插入前请检查来源页和许可条件；搜索结果不等于已获授权。

图片加载、搜索服务和直链需要联网。确认许可适用于你的用途后再插入；公众号编辑器可能仍要求下载并上传图片。
使用说明：这是一个单文件本地工具，图片搜索通过 Wikimedia Commons API 在页面内显示候选；选中后插入图片直链和来源/许可说明，但不会替你确认授权或上传图片到公众号。富文本复制依赖浏览器权限；失败时请用“导出 HTML”或明确手动选择预览内容。发布前请用手机预览。
