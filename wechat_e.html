公众号自动排版工具

粘贴 Markdown → 自动排版预览 → 复制到微信公众号编辑器。纯本地运行，不上传文章。

① 粘贴文章 / Markdown

支持标题、列表、引用、加粗、分割线
可用标记：
## 小标题 → 小标题；**加粗** → 加粗；==核心观点== → 酒红色重点；++需要强调的句子++ → 酒红色下划线；{{概念}} → 蓝色概念；> 引用 → 引用块。
图片占位可写 [图片：图片内容描述]，预览会提供“搜索图片”入口；若要在预览中显示真实图片，请使用 ![图片说明](图片直链)。搜索结果需自行核对来源与授权。
输入内容后，右侧会自动预览。

② 排版预览

预览区可滚动

文章预览会显示在这里。

使用说明：这是一个单文件本地工具，保存后用浏览器打开即可使用。图片占位可一键打开图片搜索；只有写入可访问的图片直链（![说明](图片URL)）后，预览才会显示真实图片。图片搜索不会自动取得授权，也不会自动把网络图片上传到公众号。复制富文本功能依赖浏览器权限；若复制失败，可使用“导出 HTML”，或在预览区全选复制。发布前请用手机预览。
