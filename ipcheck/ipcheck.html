1. ipinfo.io - 确认IP地址、地理位置和ISP类型 (最重要！⭐⭐⭐)

  • 点击链接后，页面会显示你的IP信息。
  • 检查要点：
    • `ip`：显示的IP地址是否为你购买的**美国IP**。
    • `city`, `region`, `country`：地理位置是否显示为**美国的城市和州**。
    • `org`：这是最关键的！ 应该显示为美国的**住宅互联网服务提供商 (ISP) 名称**，例如 `AT&T Services, Inc.`, `Comcast Cable Communications, LLC`, `Spectrum` 等。绝不能是云服务商的名字（如 AWS, Google LLC, Microsoft Corporation）。

2. ipleak.net - 综合性泄露检查 (DNS泄露、WebRTC泄露)

  • 点击链接后，等待页面加载完毕，它会自动进行多项检测。
  • 检查要点：
    • Your IP Addresses (你的IP地址): 确认显示的IP地址是你的美国IP。
    • DNS Addresses (DNS地址): 这是防止真实位置暴露的关键！ 确保所有列出的DNS服务器的IP地址和地理位置都显示为美国。 如果出现任何非美国（尤其是中国）的DNS地址，说明你的DNS泄露了，非常危险！
    • WebRTC Detection (WebRTC检测): 确认这里显示的IP地址只包含你的美国IP。如果出现了你真实的中国IP地址，则说明存在WebRTC泄露。

3. whoer.net - 综合匿名性与环境一致性检查

  • 点击链接后，页面会显示一个关于你匿名性的概览。
  • 检查要点：
    • Anonymity (匿名性): 分数尽可能高，理想情况是100%。
    • IP Address, DNS, Country (IP地址、DNS、国家): 再次确认它们都显示为美国。
    • System Time (系统时间) 和 Browser Language (浏览器语言): 确保它们与你目标模拟的美国时区和英文（美国）设置完全一致。不一致会降低“真实性”。

4. TikTok 应用本身 - 内容流验证 (最终效果)

当所有技术性检查都通过后，你才能打开手机上的TikTok应用（请确保Shadowrocket等代理工具已连接）。

检查要点：

  • 观察“为您推荐（For You Page, FYP）”页面上刷到的视频内容。
  • 预期结果： FYP应该充满英文视频，内容主题（如热门挑战、新闻、生活场景、本地口音等）应符合**美国当地的文化和趋势**。如果依然刷到大量非英语或明显非美国区的内容，说明TikTok可能仍然没有把你识别为美国用户，需要进一步检查环境配置。
